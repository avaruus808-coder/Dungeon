# Dungeon

Ilmainen, selaimessa toimiva Doom-henkinen FPS-prototyyppi. Projekti käyttää Three.jsia, TypeScriptiä ja Viteä.

## Käynnistä

1. Asenna Node.js 20 tai uudempi.
2. Suorita `npm install`.
3. Suorita `npm run dev`.
4. Avaa Viten näyttämä paikallinen osoite selaimessa.

## Ohjaus

- WASD: liiku
- Hiiri: katso
- Shift: juokse
- Vasen hiiren painike: miekka
- Oikea hiiren painike: tyhjiöisku
- E: avaa ovi

## Demossa nyt

- FPS-liikkuminen ja seinätörmäykset
- Doom-henkinen ruutukartta
- lähitaistelu ja maaginen etähyökkäys
- viholliset, terveys ja kuolema
- avaimet ja lukitut ovet
- parantava taikaesine
- salainen alue ja ulottuvuusportaali
- suomenkielinen HUD ja aloitus/lopetus

Kaikki grafiikka tuotetaan ohjelmallisesti, joten projekti ei vaadi maksullisia tai lisensoituja assetteja.
